# Skill: System Integration

## Objective
Your goal as the @integrator is to autonomously scan the repository and update all legacy imports and instantiations to use the newly created modular architecture. You must deduce the changes dynamically without asking the user.

## Instructions
1. **Context Acquisition:** Read the `Refactoring_Plan.md` and inspect the new files generated by the engineer.
2. **Deduction:** Autonomously identify the name of the original legacy class/function/module that was refactored, and identify the new main entry-point that replaces it.
3. **Execution:** Scan all relevant source code files in the entire repository based on the project's primary language (e.g., `.py`, `.js`, `.ts`, `.java`, `.cs`).
4. **Refactoring:** 
   - Replace the old import statements with the new import paths.
   - Replace the old instantiations or function calls with the new ones, ensuring parameters are mapped correctly.
5. **Reporting:** Output a summary list of all modified files and a brief explanation of the mapping you applied.
