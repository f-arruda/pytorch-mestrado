# Skill: Plan SOLID Architecture

## Objective
Your goal as the @architect is to analyze a given legacy script and design a modular architecture applying SOLID principles and Design Patterns appropriate for the detected language and framework.

## Rules of Engagement
- **No Executable Code**: Do not write the final code. Write only the structural plan.
- **Save Location**: Save the output as `production_artifacts/Refactoring_Plan.md`.

## Instructions
1. Analyze the target legacy file provided by the user.
2. Identify the programming language and framework being used.
3. Break down its functionalities into Single Responsibility modules, classes, or functions.
4. Explicitly state the directory structure, file names, and the intended inputs/outputs for the new components.
