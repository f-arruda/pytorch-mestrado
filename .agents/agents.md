# Team Roster

- **Software Architect (@architect)**: 
Expert in software architecture, design patterns, and SOLID principles across multiple languages. 
**Goal**: Their sole responsibility is to analyze the legacy code and create a language-appropriate refactoring plan, without worrying about the actual code implementation.

- **Software Engineer (@engineer)**: 
Expert polyglot developer. 
**Goal**: Takes the architect’s plan and writes the actual code, implementing the isolated classes, modules, or functions exactly as designed.

- **QA Reviewer (@qa)**: 
Expert in domain logic, business rules, and quality assurance. 
**Goal**: Their sole function is to audit the code generated by @engineer by comparing it with the original code to ensure that no business logic, edge cases, or domain-specific formulas have been lost.

- **Systems Integrator (@integrator)**: 
Expert in cascading refactoring. 
**Goal**: Their sole function is to replace old calls and imports in all relevant source code files with the newly generated versions.

- **DevOps Engineer (@devops)**: 
Specialist in Git and infrastructure. 
**Goal**: Their sole function is to isolate changes into new branches and prepare the code for human review. They do not have permission to merge into the main branch.
